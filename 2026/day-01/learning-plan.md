# My 90 Days DevOps Learning Plan

## Current Level
I am a fresher and currently learning Cloud and DevOps. I have basic knowledge of Linux, Git and AWS.

## My Understanding of DevOps & Cloud
DevOps is a culture and set of practices that helps developers and operations teams work together to build, test and deploy applications faster and more reliably.

Cloud computing provides on-demand access to computing resources such as servers, storage, networking and databases over the internet.

## Why I am Learning DevOps & Cloud
- To get a high-paying IT job.
- To build real-world skills in Cloud and DevOps.
- To become a DevOps Engineer within the next year.

## My Goals for the Next 90 Days
1. Learn Linux, Git and Networking fundamentals.
2. Learn AWS, Docker, Kubernetes and CI/CD.
3. Build and deploy real-world DevOps projects on GitHub.

## Core Skills I Want to Build
1. Linux Administration & Troubleshooting
2. AWS Cloud Services
3. CI/CD and Kubernetes

## Weekly Time Budget

## How I Will Stay Consistent

## My Target
I want to become a job-ready DevOps Engineer and get my first IT job.
